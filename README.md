## 🎨 ডিজাইন ও ইউআই নির্দেশিকা (Human-Centric UX & Theme)

* **প্রাইমারি টাইপোগ্রাফি:** বিশ্বমানের **'Noto Serif Bengali'** ফন্ট দ্বারা চালিত।
* **মনস্তাত্ত্বিক কালার প্যালেট:** প্রশান্তিদায়ক **সফট ব্লু (Soft Blue - `#0284c7`)**, **মিন্ট গ্রিন (Mint Green - `#10b981`)** এবং **হোয়াইট থিম**।
* **ডায়নামিক লোগো ও অনবোর্ডিং:** প্রথমবার চালুর সময় লোগো আপলোড করার সাথে সাথে সাইডবার, ক্যাশ কাউন্টার ও প্রিন্ট মেমোতে সরাসরি রেন্ডার হয়।
* **কলারসিবল সাইডবার:** স্থান বাঁচাতে ১-ক্লিকে সাইডবার সংকুচিত (Minimize to Icons) বা প্রসারিত করা যায়।

## 💻 প্রযুক্তি কাঠামো (Tech Stack Architecture)

```
[ Frontend: React 19 + TypeScript + Vite ]
         │
         ├── UI Framework: Tailwind CSS + Lucide Icons
         ├── Primary Font: Noto Serif Bengali
         │
         ▼
[ IPC Interfacing Bridge: Tauri 2.0 Core ]
         │
         ├── Engine: Rust (Native Desktop API)
         ├── Database: SQLite 3 with FTS5 Trigram Index
         ├── Security: Argon2id Password Hashing
         └── Hardware: ESC/POS Rasterizer (USB / Serial Direct Output)
```

## 🚀 কিভাবে চালু ও বিল্ড করবেন (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন ও ওয়েব প্রিভিউ:
```bash
# প্যাকেজ সমূহ ইনস্টল করুন
npm install

# লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন (Port 3000)
npm run dev
```

### ২. ডেস্কটপ আইকন জেনারেশন (Tauri Desktop Icon Setup):
```bash
# SVG লোগো থেকে উইন্ডোজ (.ico), ম্যাক (.icns) ও লিনাক্স (.png) আইকন তৈরি করতে:
npx tauri icon public/boribox-icon.svg
```

### ৩. ডেস্কটপ এপ্লিকেশন বিল্ড করুন:
```bash
# নেটিভ ডেস্কটপ ইন্সটলার বিল্ড করতে:
npm run tauri build
```

## 📜 অনবোর্ডিং ও প্রাথমিক সেটআপ নির্দেশিকা (First-Time Setup)

1. প্রথমবার ইনস্টলেশনের পর সফটওয়্যার খুললে স্বয়ংক্রিয়ভাবে **অনবোর্ডিং সেটআপ উইজার্ড** স্ক্রিনে নিয়ে যাবে।
2. ফার্মেসির নাম, ঠিকানা, মোবাইল নম্বর, ড্রাগ লাইসেন্স নম্বর ও **ফার্মেসির লোগো (PNG/JPG)** আপলোড করুন।
3. সুপার এডমিনের ইউজারনেম, পাসওয়ার্ড ও ৪-সংখ্যার ক্যাশ কাউন্টার পিন সেট করুন।
4. তথ্য সাবমিট করলেই অফলাইন লোকাল ডেটাবেজ প্রস্তুত হয়ে যাবে এবং আপনি মূল ড্যাশবোর্ডে প্রবেশ করবেন।
